# Splunk-Projects

This repository contains a collection of projects for analyzing various types of logs using Splunk SIEM Tool. (Both Cloud & Enterprise based)

## Projects....

1. [Analyzing DNS Logs](https://medium.com/@mansisharmasidd2/investigating-dns-traffic-with-splunk-siem-a-practical-walkthrough-660570803eda?source=friends_link&sk=9f1e1e73bf80840694c400d7179d75bd) : This project is all about how to analze DNS log files using Splunk. Project shows how to upload sample log files, extracting relevant fields, analyzing DNS query patters, detecting anomalies, and monitoring DNS traffic.

2. [Analyzing HTTP Logs](https://medium.com/@mansisharmasidd2/investigating-http-traffic-with-splunk-siem-a-practical-walkthrough-b49b5555f194) : This Project is all about how to analyze HTTP log files using Splunk. Project shows how to upload sample log files, extracting relevant fields, analyzing HTTP request patterns, detecting anomalies, and monitoring HTTP traffic.
